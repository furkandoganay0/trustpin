Quickstart

Run TrustPin locally

Use Docker Compose to start the API, PostgreSQL, and Redis locally.

1. Start the stack

docker compose up --build

2. Verify the API is live

The API listens on http://localhost:8081 by default.

curl -s http://localhost:8081/v1/audit/events -H "X-Tenant-ID: t1"

3. Open the docs

  • Geliştirici dokümanları: http://localhost:8081/docs/
  • Swagger/OpenAPI: http://localhost:8081/swagger/
