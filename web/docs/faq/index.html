Frequently asked questions

Is TrustPin an authentication provider?

No. TrustPin only verifies approvals via cryptographic signatures. Authentication and identity remain in your existing stack.

Can I self‑host?

Yes. TrustPin is open‑source and built for on‑prem deployment.

Does TrustPin store private keys?

No. Private keys never leave the device. TrustPin stores only public keys.

Where do I see API schemas?

The interactive OpenAPI reference is available at /swagger/.
