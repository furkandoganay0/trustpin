Deployment

Deploy TrustPin on‑prem

TrustPin is designed to run inside your own infrastructure. The default docker‑compose stack is a starting point for production hardening.

Core services

  • API service (stateless)
  • PostgreSQL (source of truth)
  • Redis (TTL cache, nonce uniqueness)

Production checklist

  • Enable TLS termination (ingress or reverse proxy)
  • Set strong database credentials and rotate secrets
  • Back up PostgreSQL and audit data regularly
  • Pin docker image tags
  • Restrict network access to internal zones

Configuration

TrustPin is configured through environment variables. Review the compose file to tune TTLs and rate limits.
