API Overview

TrustPin API

TrustPin exposes a minimal set of endpoints for enrollment, device management, challenge lifecycle, and audit access. Responses are JSON only.

Base URL

http://localhost:8081

Core endpoints

  • POST /v1/enrollments/init — create enrollment and pairing code
  • POST /v1/devices/activate — activate device with public key
  • POST /v1/auth/challenges/init — issue challenge
  • GET /v1/auth/challenges/{id} — fetch canonical payload
  • POST /v1/auth/challenges/{id}/approve — approve with signature
  • POST /v1/auth/challenges/{id}/reject — reject with signature
  • GET /v1/auth/challenges/{id}/status — query state
  • GET /v1/audit/events — list audit events

Example: initiate enrollment

curl -X POST http://localhost:8081/v1/enrollments/init \ -H "Content-Type: application/json" \ -d '{"tenant_id":"t1","user_id":"u1"}'

Example: approve challenge

Approval requires the device signature and canonical payload.

curl -X POST http://localhost:8081/v1/auth/challenges/{id}/approve \ -H "Content-Type: application/json" \ -d '{"device_id":"dev_123","signature":"...","payload":{...}}'
